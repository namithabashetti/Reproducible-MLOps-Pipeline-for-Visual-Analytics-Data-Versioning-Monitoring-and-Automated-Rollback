02 / Recovery

Test automatic rollback

Demo Mode · Controlled test

The system tests a candidate model. If its measured quality falls too far, it brings back the earlier model automatically.

How this demonstration creates a failure
The candidate has its confidence set to 1.0, which hides detections. This is a deliberate test fault. It does not mean the trained model naturally became worse.

Allow a few minutes. The detector will switch models during this test and restore the normal detector when finished.

Datasets and actual split counts

Original images and checkpoints are preserved. The new split applies only to fresh training. The earlier models saw some images now reserved for testing, so their test scores cannot be compared on that new split.

Model numbers and acceptance

The copied demo registry calls its candidate “version 2.” The selector shows which trained source supplies it. No model is approved for production: person labels and detection quality remain incomplete. The shared validation score supports comparison, not safety certification.
